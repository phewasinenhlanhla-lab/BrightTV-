# BrightTV- # BrightTV Case Study – Viewership Analytics

## 📘 Overview
This case study explores BrightTV’s user and viewership data to identify trends and recommend strategies for growing subscriptions and engagement.

The goal is to help the Customer Value Management (CVM) team increase the active subscription base by analyzing usage behavior, peak viewing times, and content performance.

---

## 🧮 Data Sources
- **User Profiles:** BrightTV_UserProfilescsv.csv  
- **Viewership Data:** BrightTV_Viewershipcsv.csv  
- **Case Description:** BrightTV_Case_Study.pdf  

All timestamps were converted from UTC to South Africa Standard Time (UTC+2).

---

## 🔍 Methodology
1. **Data Cleaning:**  
   - Removed missing values, standardized date/time fields.  
   - Merged user and viewership data on common identifiers.  

2. **Exploratory Analysis:**  
   - Trends by weekday, hour, age, and device.  
   - Peak usage identification and session frequency metrics.  

3. **Insights Derived:**  
   - Friday and Saturday are the most active days.  
   - Monday and Tuesday show low consumption (opportunity for campaigns).  
   - Afternoon–evening sessions (12:00–20:00) are peak hours.  

4. **Recommendations:**  
   - Targeted content drops or notifications on low-consumption days.  
   - Personalized recommendations by device and age group.  
   - Introduce referral programs and free-trial campaigns.

## 💡 Key Findings
| Insight | Description |
|----------|--------------|
| **Low Consumption Days** | Monday, Tuesday |
| **Peak Hours** | 12:00 – 20:00 |
| **Top Devices** | Mobile devices dominate sessions |
| **Engagement** | Weekends show higher binge behavior |
| **Opportunity** | Increase weekday engagement via promos |
